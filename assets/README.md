# Куда класть свои картинки

Все картинки лежат в папке `assets/` рядом с `index.html`, поделены на 4 подпапки.
Игра уже настроена их подхватывать — файл появился по нужному пути и с нужным
именем → он сразу используется. Если файла нет — ничего не ломается, просто
остаётся текущее оформление (градиент/эмодзи) как было.

## 1. `assets/backgrounds/` — фон всей игры

**Файл:** `game-bg.jpg` (можно и `.png`, но тогда в `style.css` поменяй
расширение в строке `url("assets/backgrounds/game-bg.jpg")` на `.png`)
**Размер:** 1080×1920px (портрет, под телефон) — можно больше, но не меньше.
**Формат:** JPG или WebP (легче, чем PNG, для фото-фона это не важно —
прозрачность тут не нужна).

Это фон ВСЕГО приложения, под всеми карточками — он сейчас рисуется поверх
уже существующего фиолетового градиента. Картинка тёмная/приглушённая будет
смотреться лучше, чем яркая — сверху ещё лежат полупрозрачные карточки с
текстом, и на светлом фоне текст будет хуже читаться.

одна короткая правка, просто напиши мне, когда набор иконок будет готов, и
я это подключу.

## 3. `assets/ui/` — рамки, декоративные элементы интерфейса

Пока НЕ подключено напрямую ни к чему конкретному — папка создана заранее.
Кандидаты на использование здесь: рамка вокруг аватара (сейчас — простая
цветная граница через CSS), декоративная рамка вокруг золотой карточки
президента, иконка сундука вместо 🎁. Пришли, что хочешь сюда положить, и
скажи, куда именно — подключу под конкретную картинку.

**Размер:** зависит от того, что это — для рамки аватара нужен квадрат
с прозрачной серединой (например, 200×200px, PNG).

## 4. `assets/characters/` — спрайты персонажей по профессиям

Пока НЕ подключено ни к чему — папка на будущее, если решишь добавить
персонажа профессии (например, вместо 💼 эмодзи в профиле показывать
маленького нарисованного полицейского/врача/т.д.).

**Размер:** 256×256px, PNG с прозрачностью.
**Имя файла = код профессии:** `police.png`, `medicine.png`, `mchs.png`,
`education.png`, `taxi.png`, `courier.png`, `it.png`, `law.png`,
`construction.png`, `zavod.png`.

---

## Как проверить, что картинка подключилась

1. Положи файл в нужную папку с точным именем из таблицы.
2. Загрузи фронтенд на хостинг (или обнови файлы на GitHub Pages).
3. Открой игру — фон/иконка должны появиться сразу, без правок кода.

Если картинка не появилась — самая частая причина: неправильное имя файла
(регистр букв важен — `Coffee.png` не сработает, нужно `coffee.png`) или
неправильное расширение (`.jpeg` вместо `.jpg` для фона).
