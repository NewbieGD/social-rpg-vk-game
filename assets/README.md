# Кастомизация игры — что, где и как менять

Единый гайд по всему, что можно поменять под себя: картинки (и их размер на
экране, не только размер файла), тексты, названия, цвета.

**Общий принцип:** картинки лежат в `assets/` рядом с `index.html`. Файл
появился по нужному пути и с нужным именем → он сразу используется, без
правок кода. Нет файла — ничего не ломается, остаётся эмодзи/градиент, как
сейчас. **Размер САМОГО ФАЙЛА** (сколько пикселей в картинке) и **размер, в
котором она показывается на экране** — две разные вещи: ты можешь прислать
файл 500×500px, а на экране он всё равно покажется как 42×42px, если так
задано в коде. Ниже — где именно задан размер показа для каждой картинки,
и как его поменять.

## Часть 1 — Картинки, по папкам

### `assets/backgrounds/` — фоны

| Файл | Где используется | Размер файла | Формат |
|---|---|---|---|
| `game-bg.jpg` | Фон всего приложения | 1080×1920px (портрет) | JPG/WebP |
| `exam-paper-bg.jpg` | Текстура школьного экзамена/ПДД | 800×1400px | JPG |
| `gov-hall-bg.jpg` | Текстура вкладки «Государство» | 800×1000px | JPG |

**Про размер показа:** фоны устроены иначе, чем иконки — они всегда
растягиваются на весь свой блок через CSS-свойство `background-size: cover`
(строка 18 в `style.css` для игрового фона, и рядом со строками 1683/1897
для двух остальных). Значит менять тут особо нечего — какой бы файл ты ни
положил, он сам подстроится под экран. Если хочешь изменить **как именно**
он обрезается (например, показывать больше сверху, а не по центру) — ищи
рядом `background-position` в тех же местах.

**Как поменять размер показа:**
- Ряд активных бафов в профиле — файл `style.css`, правило `.buff-icon-btn`
  (там же и `.buff-icon-btn img` сразу под ним — трогать нужно ОБА: первое
  задаёт размер самой кнопки-квадрата, второе говорит картинке внутри
  заполнить её целиком).
- Попап с описанием бафа — правило `.chest-overlay-icon-img` в том же файле.

**Если хочешь НЕ квадрат** (например, 128×30 вместо 128×128): меняешь
`width`/`height` в найденном правиле на любые свои числа (например,
`width: 60px; height: 20px;`). У картинки внутри стоит `object-fit: contain`
— значит она впишется целиком без искажения, но по бокам/сверху-снизу
может остаться немного пустого места, если пропорции файла и кнопки не
совпадают. Если вместо этого хочешь, чтобы картинка ЗАПОЛНЯЛА всю кнопку
без пустот (но обрезалась по краям при несовпадении пропорций) — поменяй
`object-fit: contain` на `object-fit: cover` в том же правиле.

**Как поменять размер показа:** файл `style.css`, правило `.profile-nav-icon`

поменяй на `object-fit: contain`.

расширение `.png` → `.gif` прямо в коде — файл `js/screens/profile.js`,
искать строку с этой кнопкой (например, `addProfileNavBtn(navCard,
"nav-inventory.png", ...)`) и поменять расширение в кавычках. Без этой
правки файл `.gif` не подхватится. Если не хочешь лезть в код — пришли
гифки, укажи для каких кнопок, и я поменяю сам.

### `assets/houses/` — скины домов

Зависит от купленной в Магазине косметики дома.

| Товар в Магазине (Косметика) | Файл |
|---|---|
| Особняк | `house-mansion.png` |
| Современный дом | `house-modern.png` |
| Замок | `house-castle.png` |

**Файл советуем:** 96×96px, прозрачный фон, PNG или GIF.

**Показывается в ДВУХ разных местах с разным размером показа:**
1. **Кнопка-квадрат «Твой дом» в профиле** — файл `style.css`, правило
   `.profile-asset-btn` (сама кнопка) и `.profile-asset-btn img` под ним
   (картинка внутри, сейчас `object-fit: cover`). Дефолт — 40×40px (задан
   в `.profile-asset-btn`).
2. **Попап при клике на эту кнопку** (крупный превью) — правило
   `.profile-asset-preview`, дефолт 96×96px.
3. **Карта частного сектора** — здесь размер задан НЕ в CSS, а прямо в коде
   `js/screens/map.js`, в строке с `<image href="assets/houses/...`. Там
   написано `width="48" height="48"` и рядом `x="-24" y="-24"` — **важно:**
   `x`/`y` должны быть ровно минус ПОЛОВИНА от `width`/`height`, иначе
   картинка съедет со своей точки на карте. Если меняешь `width="60"
   height="60"` — не забудь поменять и `x="-30" y="-30"`. Там же уже стоит
   `preserveAspectRatio="xMidYMid meet"` — это защита от искажения, если
   поставишь не квадратный размер (например, 60×20) — картинка впишется
   целиком без растягивания, просто может остаться пустое место по бокам.

Если куплено сразу несколько скинов — показывается самый престижный
(порядок: Замок > Современный дом > Особняк).

## Часть 2 — Тексты и названия

Это уже не картинки, а строки в коде backend. После правки нужно заново
задеплоить backend (загрузить изменённый файл туда же, где сейчас работает
сервер).

### Названия профессий

**Файл:** `bot/professions.py`, словарь `PROFESSIONS`:
```python
"police": {"name": "Полиция", "category": "physical", "base_rate": 10},
```
Меняешь текст в кавычках после `"name":` — не трогай `category` и
`base_rate`, это игровая механика.

### Названия и описания товаров в Магазине

**Файл:** `bot/items.py`, словарь `SHOP_ITEMS`:
```python
"coffee": {
    "name": "Кофе", "category": "bonus", "price": 50, ...
    "description": "☕ +20% к доходу на ближайшие 6 часов...",
},
```
Меняй текст после `"name":` и `"description":`.

### Названия косметики (скины дома/машины, рамки, значки)

**Файл:** `bot/cosmetics.py`, словарь `COSMETIC_ITEMS`:
```python
"castle_house": {
    "title": "Дом: замок", "price_votes": 90,
    "description": "Меняет внешний вид твоего дома на карте на настоящий замок...",
},
```

### Название страны, флаг

Не в коде — президент меняет их прямо в игре (вкладка Государство →
предложить новое название/флаг → голосование граждан).

### Тексты вопросов школьного экзамена и теста ПДД

**Файлы:** `bot/exam_questions.py` (школьный экзамен), `bot/pdd_questions.py`
(тест на права):
```python
{"text": "Ты нашёл на улице подозрительно дорогой телефон.",
 "options": [
     {"text": "Отнесу в полицию", "risk": 0, "logic": 1, ...},
     ...
 ]},
```
Меняй только текст в кавычках после `"text":` — цифры рядом (`risk`,
`logic` и т.д.) считают итоговую профессию, их лучше не трогать.

## Часть 3 — Цвета и общий стиль

Честно: единой «одной переменной для всех цветов» в игре нет — цвета
прописаны внутри правил под каждый экран отдельно. Всё в файле `style.css`:

| Что | Искать по строке | Что означает |
|---|---|---|
| Общий фон приложения | `body {` (самое начало файла) | Базовый градиент под всем |
| Золотой акцент («Государство», попапы) | `#d4af37` (много раз по файлу) | Основной золотой цвет темы |
| Фиолетовый акцент (кнопки, конфетти) | `#6c5ce7` / `#a29bfe` | Основной фиолетовый цвет темы |
| Тема экзамена («бумага») | `.exam-paper {` | Кремовый/бумажный цвет |
| Тема рынка (дерево) | `.market-section-card {` | Коричнево-золотистый |
| Тема карты | `.map-fullscreen-overlay {` | Тёмно-синий/фиолетовый |
| Тема пожара (событие) | `.fire-event-theme` | Красный |

Если решишь сменить общую палитру — проще всего сказать мне, какие именно
цвета хочешь, и я пройдусь по всем нужным местам сразу.

## Часть 4 — Звуки

Все звуки (успех, ошибка, монетка, сообщение в чате, тревога события) — не
файлы, а генерируются прямо кодом через Web Audio API (`js/fx.js` и функция
`playAlertSound` в `js/shell.js`). Заменить на свои mp3/wav — отдельная,
более крупная правка. Скажи, если понадобится.

## Как проверить, что картинка подключилась

1. Положи файл в нужную папку с точным именем из таблицы.
2. Загрузи фронтенд на хостинг.
3. Открой игру — картинка должна появиться сразу.

Если не появилась — самая частая причина: неверное имя файла (регистр
важен — `Coffee.png` не сработает, нужно `coffee.png`) или неверное
расширение (`.jpeg` вместо `.jpg`).
